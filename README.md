# 🗂️ Lenguajes de marcado: `XML`
![XML Badge](https://img.shields.io/badge/XML-005FAD?logo=xml&logoColor=fff&style=plastic)

> 🌈 Bienvenidinchi al repo de **XML**!!
> Aquí irás encontrando ejemplos claros, reglas importantes y ejercicios para entender cómo funcionan los **lenguajes de marcado**… sin liarte la vida 😌

---

## 🚀 Requisitos previos

- 🧪 **Editor recomendado:**  
  - Visual Studio Code (con la extensión “XML Tools”)  
  - *o cualquier editor que te guste mientras resalte etiquetas .*  
- 📄 **Conocimientos básicos:**  
  - Qué es una etiqueta `<etiqueta>`  
  - Cómo se abre y se cierra  
  - Qué es un documento bien formado  

> 📝 XML **no es un lenguaje de programación**, es un **lenguaje de marcado** pensado para *describir datos*.  
> No ejecuta nada: solo estructura información.
